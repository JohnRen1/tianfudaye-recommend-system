# AI 财税体检与私域转化平台 MVP 四周交付计划

## 一、项目目标

本项目 MVP 计划在 **4 周内完成首版交付**，采用 **vibe coding + AI 辅助开发 + 成熟组件复用** 的方式，优先跑通沙龙用户沉淀和线索转化闭环。

MVP 核心业务链路如下：

```text
活动二维码 → 活动落地页 → 用户登录 → 资料领取 → AI 税务问答 → 风险测评 → 风险报告 → 预约顾问 → 线索后台 → 顾问跟进
```

首版交付目标是让系统具备真实沙龙场景试运行能力。

## 四、关键难点与处理方案

### 1. 微信登录

微信登录涉及授权配置、回调域名、openid 获取和手机号绑定，存在一定联调不确定性。

处理方案：

- 手机号登录作为稳定主链路。
- 微信登录并行接入。
- 微信授权失败时降级为手机号登录。
- 后续支持手机号与微信 openid 补绑。

### 2. RAG 问答

财税问答对准确性和合规性要求较高。

处理方案：

- 首版优先使用人工整理的 FAQ / Markdown 知识。
- 不做复杂 PDF 解析和 OCR。
- 所有 AI 回答强制包含免责声明。
- 高风险问题强制提示人工顾问介入。
- 第 4 周集中进行 RAG 效果和安全边界测试。

### 3. 风险测评报告

风险等级必须可解释，不能由大模型直接决定。

处理方案：

- 风险分数由规则引擎计算。
- AI 只负责生成自然语言报告。
- 报告生成失败时使用模板报告兜底。
- 高风险报告强制引导预约顾问。

## 五、MVP 暂不纳入范围

为保证 4 周交付，以下功能不进入 MVP 首版：

- 活动复盘 Agent
- 顾问自动分配
- 企微集成
- 社群自动引导
- 高频问题自动分析
- 知识库复杂版本管理
- OCR 文档解析
- 测评题库后台动态配置
- 短信通知
- 复杂图表分析
- 在线支付
- CRM 集成
- 多机构 SaaS 化

以上能力进入后续 P1 / P2 迭代。

## 六、最终交付标准

MVP 完成后，系统应达到以下标准：

1. 用户可以通过活动二维码进入指定活动页。
2. 用户可以登录并领取资料。
3. 用户可以使用 AI 税务问答。
4. 用户可以完成风险测评并查看报告。
5. 高风险用户可以被识别并生成线索。
6. 用户可以提交预约顾问申请。
7. 顾问可以在后台查看并跟进线索。
8. 后台可以查看活动、用户、资料、问答、测评和线索数据。
9. AI 回答具备免责声明和高风险转人工提示。
10. 系统具备真实沙龙场景试运行能力。

---

## 七、汇报结论

本项目 MVP 采用四周交付计划，优先完成沙龙用户沉淀、AI 咨询、风险测评、预约顾问和线索转化闭环。

第 1 周完成基础主链路，第 2 周完成 AI 与测评闭环，第 3 周完成线索后台闭环，第 4 周完成联调、AI 安全测试和上线准备。

通过 vibe coding 和成熟组件复用，项目可以在 4 周内完成首版 MVP，并支持真实沙龙活动试运行。
