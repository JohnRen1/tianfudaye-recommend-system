## 二、设计原则与审计总纲对应

| 审计问题 | 对应决策 | 契约体现位置 |
|----------|----------|-------------|
| **S1** — 跨实体用活动名称字符串关联 | `activityId` 外键贯穿 qrCodes / materials / users / leads | `ActivityListItemDTO`、`UserQueryDTO`、`LeadQueryDTO` |
| **S2** — 邀请码拼接逻辑错误 | `ActivityQrInfoDTO` 返回真实 inviteCode / qrCodeId，不再拼接 id+INVITE | `ActivityQrInfoDTO` |
| **S4** — 两端字段名不一致 | admin 存 teacher/place/startAt；落地页渲染用 speaker/location/date/time，后端转换 | `ActivityCreateDTO`、`EventLandingDTO` |
| **S4** — status 存中文字符串 | `ActivityStatus` 枚举统一英文值，展示层映射 `ACTIVITY_STATUS_LABEL` | `activity.ts` |
| **S5** — 统计字段缺失 | `ActivityStatisticsDTO` 按 activityId 归因，替代全局 funnelData | `ActivityStatisticsDTO` |
| **S6** — 转化率前端用写死系数计算 | `conversionRate` / `leadRate` 由后端计算后返回 | `ActivityStatisticsDTO` |

## 三、枚举定义

### 3.1 ActivityStatus（活动状态）

| 英文值 | 中文展示标签 | 说明 |
|--------|-------------|------|
| `published` | 已上架 | 对外开放，落地页可见 |
| `draft` | 草稿 | 未发布，仅管理员可见 |
| `closed` | 已下架 | 停止运营，落地页展示"已结束" |

### 3.2 ActivityType（活动形式）

| 英文值 | 中文展示标签 |
|--------|-------------|
| `offline` | 线下活动 |
| `online` | 线上直播 |
| `hybrid` | 线上+线下 |

## 五、DTO 详情

### 5.1 ActivityCreateDTO

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | `string` | 是 | 活动名称 |
| `theme` | `string` | 是 | 活动主题标签 |
| `startAt` | `string` | 是 | 开始时间，ISO 8601 datetime |
| `endAt` | `string` | 否 | 结束时间，ISO 8601 datetime |
| `place` | `string` | 是 | 活动地点（admin 侧字段名） |
| `teacher` | `string` | 是 | 主讲老师姓名（admin 侧字段名） |
| `speakerTitle` | `string` | 是 | 主讲老师职称（落地页展示用，admin 需补全） |
| `status` | `ActivityStatus` | 是 | 活动状态 |
| `description` | `string` | 是 | 活动简介 |
| `coverImage` | `string` | 否 | 活动封面图 URL |
| `materialIds` | `string[]` | 否 | 关联资料 id 数组（外键，S1） |
| `type` | `ActivityType` | 否 | 活动形式 |

**服务端生成字段（不接受客户端提交）**：`id`、`createdAt`、`updatedAt`、`creatorId`、统计计数字段（`scan`/`register`/`materialClaims`/`assessments`/`appointments`/`highIntentLeads`）。

### 5.2 ActivityUpdateDTO

| 字段 | 类型 | 说明 |
|------|------|------|
| `coverImage` | `string \| null` | null 表示删除封面图 |

### 5.3 ActivityStatusUpdateDTO

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `status` | `'published' \| 'closed'` | 是 | 仅允许上架或下架 |

## 六、错误码

| 错误码 | HTTP 状态 | 说明 |
|--------|----------|------|
| `ACTIVITY_NOT_FOUND` | 404 | 活动不存在 |
| `ACTIVITY_DELETE_PUBLISHED` | 409 | 已上架活动不允许直接删除 |
| `ACTIVITY_PUBLISH_INCOMPLETE` | 422 | 上架时缺少必填字段（description / coverImage） |
| `ACTIVITY_BULK_IDS_EMPTY` | 400 | 批量操作 activityIds 为空 |
| `ACTIVITY_BULK_IDS_TOO_MANY` | 400 | 批量操作超出上限（100） |
| `ACTIVITY_MATERIAL_NOT_FOUND` | 404 | 关联资料 id 不存在 |
| `ACTIVITY_QR_NOT_GENERATED` | 404 | 活动尚未生成专属二维码 |
| `ACTIVITY_STATS_EMPTY` | 404 | 活动统计数据为空（刚创建，无行为数据） |
| `ACTIVITY_PERMISSION_DENIED` | 403 | 权限不足 |
| `ACTIVITY_EXPORT_EMPTY` | 422 | 筛选结果为空无法导出 |
| `ACTIVITY_CLOSED` | 410 | 落地页：活动已结束 |

## 九、关键字段约定

### 9.1 admin 字段 vs 落地页字段映射

| admin 侧字段 | 落地页侧字段 | 转换方式 |
|-------------|------------|---------|
| `name` | `title` | 直接映射，字段名不同 |
| `teacher` | `speaker` | 直接映射，字段名不同 |
| `speakerTitle` | `speakerTitle` | 相同（需 admin 侧补全） |
| `place` | `location` | 直接映射，字段名不同 |
| `startAt`（ISO 8601） | `date`（"2026年6月18日"） | 后端格式化日期部分 |
| `startAt` + `endAt` | `time`（"14:00 - 17:00"） | 后端格式化时间区间 |
| `description` | `description` | 相同（需 admin 侧补全） |
| `coverImage` | `coverImage` | 相同（需 admin 侧补全） |

### 9.2 漏斗数据归因

原 mock 中 `funnelData` 为全局静态数组，所有活动的数据抽屉均显示同一组漏斗数据。  
**契约要求**：`GET /api/admin/activities/:id/stats` 按 `activityId` 归因返回该活动的漏斗数据，不使用全局聚合。

### 9.3 materialOptions 修复

原 mock 中 `materialOptions.value` 使用 `'risk-list'` 等业务代码，与 `materialItems.id` 格式不一致。  
**契约要求**：关联资料通过 `materialIds: string[]`（UUID 数组）传递，展示层通过 `/api/admin/materials/options` 动态加载选项。

## 十二、遗留不确定项（需产品确认）

| # | 问题 | 当前契约假设 | 需要决策的内容 |
|---|------|------------|--------------|
| 1 | 活动是否允许未填 `coverImage` 上架？ | `coverImage` 非必填，上架时若为 null 落地页使用默认背景 | 产品确认：上架时 coverImage 是否强制 |
| 2 | 活动的 `materialOptions` 如何动态加载？ | 通过 `GET /api/admin/materials/options` 全量加载，支持 activityId 筛选已关联项 | 产品确认：下拉是否需要分页或搜索 |
| 3 | 漏斗步骤是否固定 8 步，还是可配置？ | 固定 8 步（与 funnelData 全局步骤名对齐），值按活动归因 | 产品确认：是否需要支持自定义漏斗步骤 |
