## 二、设计原则与审计总纲对应

| 审计问题 | 对应决策 | 契约体现位置 |
|----------|----------|-------------|
| **S1** — `qaRecords.user` / `qaRecords.phone` 字符串关联 | `userId` / `activityId` 改外键；`userName` / `activityName` 服务端 join | `QaRecordListItemDTO` |
| **S3** — 落地页 AI 问答无落库逻辑 | `POST /api/ai/chat` 服务端同步落库，返回 `qaRecordId` | `AiChatRequestDTO`、`AiChatResponseDTO` |
| **S4** — 两端字段名不一致（`risks` vs `involvedRisks`，`suggestion` vs `suggestions`，`manual` vs `advisorRecommended`） | 统一为全称字段名，double-check 两端同步 | `AiAnswerBodyDTO` |
| **S4** — 落地页 `riskLevel='uncertain'` 无法映射到统一枚举 | `uncertain` 落库时映射为 `riskLevel='medium'` + `needsConfirmation=true`；RiskLevel 枚举保持 4 值 | `AiAnswerBodyDTO.needsConfirmation` |
| **S4** — 风险等级筛选项只有"高风险/中风险"（缺 low / critical） | `QaRecordQueryDTO.riskLevel` 支持全部 4 值 | `QaRecordQueryDTO` |
| **S5** — `sessionId` 等字段命名不规范 | `sessionId` 统一用于多轮对话上下文，首次提问不传，后端生成后返回 | `AiChatRequestDTO`、`AiChatResponseDTO` |
| **S6** — 统计卡片依赖前端遍历全量数组 | `QaRecordStatisticsDTO` 从后端聚合计算 | `QaRecordStatisticsDTO` |

## 三、枚举定义

### uncertain → medium + needsConfirmation 映射规则

落地页 AI 回答中存在 `riskLevel="uncertain"` 的情况，契约决策如下：

- **落库时**：`riskLevel` 映射为 `"medium"`，独立布尔字段 `needsConfirmation` 设为 `true`
- **admin 侧**：通过 `needsConfirmation=true` 识别此类记录，展示"建议结合实际确认"提示
- **RiskLevel 枚举**：保持 `low / medium / high / critical` 四值不变，`uncertain` 不进枚举

## 五、DTO 详情

### 5.1 AiChatRequestDTO（落地页）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question` | `string` | 是 | 用户提问原文，不超过 2000 字符 |
| `sessionId` | `string \| null` | 否 | 会话 id；首次提问不传，服务端生成后返回；后续提问携带以实现多轮上下文 |
| `activityId` | `string \| null` | 否 | 来源活动 id（S2 归因链，从 URL 参数读取） |

### 5.2 AiAnswerBodyDTO

AI 回答结构体，同时用于落地页响应（`AiChatResponseDTO.answer`）和 admin 详情抽屉（`QaRecordDetailDTO.aiAnswer`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `questionUnderstanding` | `string` | AI 对用户问题的理解说明 |
| `initialJudgment` | `string` | AI 初步判断文本 |
| `involvedRisks` | `string[]` | AI 识别的涉及风险列表（统一为数组，替代 admin mock 的单字符串 `risks`） |
| `suggestions` | `string[]` | AI 处理建议列表（统一为数组，替代 admin mock 的单字符串 `suggestion`） |
| `riskLevel` | `RiskLevel` | 风险等级（4 值枚举，`uncertain` 映射为 `medium`） |
| `advisorRecommended` | `boolean` | 是否建议人工顾问介入（替代 admin mock 的 `manual` 字段） |
| `needsConfirmation` | `boolean` | 是否为"建议结合实际确认"状态（落地页 `uncertain=true` 的持久化语义） |
| `knowledgeItemIds` | `string[]` | 引用的知识库条目 id 列表（RAG 预留，当前阶段为空数组） |

### 5.3 AiChatResponseDTO（落地页）

| 字段 | 类型 | 说明 |
|------|------|------|
| `qaRecordId` | `string` | 落库生成的问答记录 id（UUID），用于后续关联预约等操作 |
| `sessionId` | `string` | 本轮所属会话 id，下次提问时携带 |
| `answer` | `AiAnswerBodyDTO` | AI 结构化回答体 |
| `summary` | `string` | AI 生成的问题摘要（admin 列表展示用） |
| `tags` | `string[]` | AI 自动打标的标签列表 |

### 5.4 QaRecordListItemDTO

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | UUID 主键 |
| `userId` | `string` | 提问用户外键（S1：不存姓名字符串） |
| `userName` | `string` | 提问用户姓名（服务端 join） |
| `userPhone` | `string` | 提问用户脱敏手机号（服务端 join） |
| `summary` | `string` | 问题摘要（AI 生成，不截断） |
| `tags` | `string[]` | AI 自动打标的标签数组 |
| `type` | `string` | 问题类型（如"公转私风险"/"政策咨询"） |
| `riskLevel` | `RiskLevel` | 风险等级（统一英文枚举，S4） |
| `advisorRecommended` | `boolean` | 是否建议人工顾问介入（对应 admin mock 的 `manual` 字段，S4） |
| `needsConfirmation` | `boolean` | 是否为"建议结合实际确认"状态 |
| `activityId` | `string \| null` | 来源活动外键（S1） |
| `activityName` | `string \| null` | 来源活动名称（服务端 join） |
| `sessionId` | `string \| null` | 会话 id（多轮对话关联用） |
| `createdAt` | `string` | 提问时间，ISO 8601（替代 mock 的 `time` 非标格式） |

### 5.5 QaRecordDetailDTO

继承 `QaRecordListItemDTO` 全部字段，额外增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| `originalQuestion` | `string` | 用户问题原文（完整文本） |
| `aiAnswer` | `AiAnswerBodyDTO` | AI 回答完整结构体 |
| `advisorNote` | `string \| null` | 顾问备注（独立字段，不覆盖 AI 内容） |
| `assignedAdvisorId` | `string \| null` | 已分配顾问外键（S1） |
| `assignedAdvisorName` | `string \| null` | 已分配顾问姓名（服务端 join） |
| `hasLead` | `boolean` | 是否已生成线索 |
| `leadId` | `string \| null` | 已生成的线索 id（hasLead=true 时返回） |

列表页顶部 3 张统计卡片（所有值为 `number`）：

## 八、AI 问答落库流程

```
用户提问
  │
  ▼
POST /api/ai/chat
  │
  ├─► 服务端调用 AI 模型生成回答
  │     ├─ riskLevel="uncertain" → 存储为 riskLevel="medium" + needsConfirmation=true
  │     └─ involvedRisks/suggestions 统一为数组
  │
  ├─► 服务端将问答落库（qa_records 表）
  │     ├─ userId：从 JWT 读取（未登录时为 null）
  │     ├─ activityId：从请求体读取（S2 归因）
  │     └─ sessionId：首次提问时服务端生成
  │
  └─► 响应前端
        ├─ qaRecordId：问答记录 id（落地页可用于关联预约）
        ├─ sessionId：下次提问时携带
        └─ answer：AiAnswerBodyDTO 结构化回答
```

## 十二、遗留不确定项（需产品确认）

| # | 问题 | 当前契约假设 | 需要决策的内容 |
|---|------|------------|--------------|
