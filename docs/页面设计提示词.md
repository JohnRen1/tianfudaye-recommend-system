一、整体设计总提示词
可先把这段作为项目级提示词发给 v0.app，让它统一设计语言。

请为一个“AI 财税体检与私域转化平台”设计一套高质量产品界面原型，包含移动端小程序界面和 Web 管理后台界面。
产品定位：
这是一个服务于税务咨询公司沙龙获客和私域转化的平台。用户通过沙龙二维码进入活动页，领取资料，使用 AI 税务助手，完成企业财税风险测评，查看风险报告，并预约人工顾问。后台用于运营人员管理活动、二维码、资料、用户、AI 问答记录、测评报告和销售线索。
整体设计风格：
- 专业、可信、合规、轻量化、转化导向。
- 适合财税、企业服务、咨询行业。
- 主色使用深蓝色或税务蓝，辅色使用金色 / 橙色强调转化按钮。
- 页面需要有明显的信任感、专业感和安全感。
- 移动端要符合微信小程序使用习惯，底部 Tab、卡片式布局、清晰 CTA。
- 后台要现代化 SaaS 风格，左侧导航、顶部筛选、数据卡片、表格、详情抽屉、状态标签。
- 所有 AI 回答、风险报告和建议区域必须展示免责声明。
- 高风险内容需要用醒目的红色 / 橙色风险标签，并引导“预约顾问”。
品牌视觉关键词：
专业财税、AI 助手、企业风险体检、沙龙转化、顾问服务、线索管理、私域运营。
请生成：
1. 移动端小程序核心页面设计。
2. Web 管理后台核心页面设计。
3. 关键交互流程设计。
4. 页面状态设计，包括未登录、加载中、空状态、成功状态、高风险提醒状态。

1. 用户进入测评起始页。
2. 点击“开始测评”。
3. 依次填写企业基础信息和风险问题。
4. 页面显示答题进度。

   - 0-30：低风险
   - 31-60：中风险
   - 61-80：高风险
   - 81-100：严重风险
8. AI 根据规则评分结果生成自然语言报告，但不直接决定风险分。
9. 展示基础报告。
10. 用户点击查看完整报告时，如果未登录，需要登录并留手机号。
11. 高风险和严重风险用户自动生成线索。
12. 报告保存到用户中心。
测评维度：
- 企业基础信息
- 发票合规风险
- 公转私风险
- 企业所得税风险
- 增值税风险
- 个税社保风险
- 成本费用风险
- 长期零申报风险
- 税负率异常风险
- 税务稽查应对风险
报告内容：
- 总体风险等级
- 风险分数
- 主要风险模块
- 每个模块的风险说明
- 初步整改建议
- 顾问解读建议
- 免责声明
交互状态：
- 未完成题目不能下一步。
- 生成报告时显示加载动画。
- 高风险报告突出“预约顾问解读”。
- 完整报告未解锁时展示部分内容遮罩。
